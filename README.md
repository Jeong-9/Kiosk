### 📌 프로젝트 개요
뚜띠쿠치나(Tutti Cucina) 레스토랑의 키오스크 주문 시스템입니다.
고객이 직접 메뉴를 선택하고, 결제 방식을 선택하며, 이벤트 응모와 회원가입까지 한 번에 처리할 수 있는 통합 주문 흐름을 구현했습니다.

### 🖥️ 개발 환경
| 항목 | 내용 |
| :--- | :--- |
| 언어 | C# |
| 프레임워크 | .NET Windows Forms(.NET6.0) |
| IDE | Visual Studio 2022 |
| 대상 OS | Windows |

### 📂 프로젝트 구조

```text
kio/
├── Program.cs          # 앱 진입점 (Form1 시작)
├── Form1.cs            # 시작 화면 (입장 버튼)
├── Loading1.cs         # 로딩 화면 (2초 후 메뉴로 이동)
├── menu.cs             # 메뉴 주문 화면 (100초 타이머)
├── PaymentForm.cs      # 결제 화면 (100초 타이머)
├── Finish.cs           # 결제 완료 화면 (5초 후 종료)
└── *_Designer.cs       # Visual Studio 자동 생성 디자이너 파일
```

### 🔄 화면 흐름 (Flow)

```text
[Form1: 시작 화면]
      ↓ 입장 버튼 클릭
[Loading1: 로딩 (2초)]
      ↓ 자동 전환
[menu: 메뉴 선택 (최대 100초)]
      ↓ 결제 버튼 클릭
[Loading2: 로딩]
      ↓ 자동 전환
[PaymentForm: 결제 (최대 100초)]
      ↓ 결제 완료
[Loading3: 로딩]
      ↓ 자동 전환
[Finish: 완료 화면 (5초)]
      ↓ 자동 종료

※ 타이머 초과 시 → Form1(시작 화면)으로 자동 복귀
```


### ✨ 주요 기능
🏠 시작 화면 (Form1)

레스토랑 로고 및 환영 문구 표시
"가게 안으로 입장하기" 버튼으로 주문 시작

⏳ 로딩 화면 (Loding1)

2초 타이머 후 메뉴 화면으로 자동 전환
브랜드 이미지 표시

🍕 메뉴 선택 (menu)

카테고리별 메뉴 구성

샐러드: 치즈연어, 토마토, 허브치킨
파스타: 새우해물토마토, 파김치토마토, 크랩미트크림, 까르보나라, 봉골레오일, 감바스오일
피자: 고르곤졸라, 마르게리타, 리코타 칼조네
스테이크
음료: 아메리카노, 카페라떼, 소다, 에이드, 물


수량 선택 (NumericUpDown, 1~10개)
총 금액 계산 (항목별 합계 실시간 출력)
전체 취소 기능 (초기화)
100초 제한 타이머 (초과 시 시작 화면 복귀)

💳 결제 화면 (PaymentForm)

이전 화면에서 받은 총 금액 표시
결제 수단 선택 (ComboBox)

신용카드 (일시불 / 3·6개월 할부)
계좌이체 (국민·농협·신한·기업·하나)
포인트 (마이신한·삼성·M포인트·L.POINT·모두우리)


요구사항 접수 텍스트박스
이벤트 응모 (개인정보 동의 여부 선택)
회원가입 동의 (스탬프 카드 발급 연계)
모든 항목 확인 후 결제 완료 처리
100초 제한 타이머 (초과 시 시작 화면 복귀)

✅ 완료 화면 (Finish)

"결제가 완료되었습니다. 조금만 기다려주세요." 안내
5초 후 자동으로 화면 닫힘
